Programming Lessons

Lesson 1: Variables

Variables store information in programming languages. You can save names, numbers and text inside variables.

let name = "Kingsley"; console.log(name);

Lesson 2: Functions

Functions are reusable blocks of code that perform tasks.

function greet(){ alert("Welcome to coding") }

Lesson 3: Loops

Loops repeat code multiple times automatically.

for(let i = 1; i <= 5; i++){ console.log(i) }

Lesson 4: Conditions

Conditions help programs make decisions.

let age = 18; if(age >= 18){ console.log("Adult") }else{ console.log("Minor") }
